# Skin—Clinic shop

Готовый адаптивный frontend интернет-магазина Skin—Clinic по переданным Figma CSS-спецификациям и документации Sandbox Shop API.

## Запуск

1. Распакуйте архив.
2. Откройте папку проекта в VS Code.
3. Запустите `index.html` через расширение Live Server (рекомендуется), либо разместите папку на любом статическом хостинге.

API подключён к `https://api.wepro.uz/sandbox-shop`.

## Реализовано

- Главная страница: hero, хиты продаж, категории, новинки, footer.
- Каталог: фильтр по категории и цене, пагинация.
- Страница товара: добавление в корзину, список и отправка комментариев.
- Регистрация и вход; токен хранится в `localStorage`.
- Личный кабинет и выход.
- Корзина: изменение количества, удаление товара, серверное оформление заказа.
- История заказов.
- Адаптивная вёрстка для планшетов и телефонов.

## Важно

- Используйте только учебные данные и придуманный пароль, как указано в API-документации.
- Изображения hero и категорий, для которых API не возвращает картинку, загружаются по внешним ссылкам. Для полного совпадения с оригинальным Figma-макетом замените их на исходные изображения из Figma.
- В загруженных материалах не было отдельных исходных JPG/PNG для всех картинок макета. Поэтому точное совпадение изображений гарантировать нельзя; геометрия и типографика собраны по переданным CSS-значениям.
